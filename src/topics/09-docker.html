Docker / infra — שירותים, פורטים, volumes

9.1 פרטים שחשוב לזכור
  • server/worker/seed = אותו image (lolsuit/server:local), 3 פקודות. ה־CMD של ה־image הוא gunicorn; compose דורס את ה־command ל־worker ול־seed.
  • Server Dockerfile: multi-stage (venv ב־/opt/venv), משתמש non-root lolsuit uid 1001, /app/uploads נוצר ב־image לפני ה־volume, healthcheck עם urllib (אין curl).
  • Web Dockerfile: node בונה dist/ (npm ci, npm run build = tsc -b && vite build), nginx unprivileged מגיש. docker-entrypoint.sh מרנדר nginx.conf.template עם API_UPSTREAM.
  • nginx locations: = /api/notifications/stream (proxy_buffering off, timeouts 3600s), = /api/uploads (client_max_body_size 6m), /api/, /assets/ (cache שנה), = /index.html (no cache), / (try_files … /index.html).
  • db healthcheck ב־TCP (-h 127.0.0.1) — כי בזמן אתחול MySQL מאזין רק ל־socket, ופינג socket היה "בריא" בזמן ש־init.sql עוד רץ.
  • env allowlist: קונטיינר רואה רק משתנים שרשומים ב־environment: של השירות שלו. משתנה ב־.env שלא רשום — לא קיים בקונטיינר.
9.2 איך מריצים ומוודאים מקומית
# הכל בדוקר (build קר לוקח כמה דקות — npm ci + vite)
docker compose up --build            # או: make up  (detached)
open http://localhost:8080
docker compose ps                    # או make ps — health של כל שירות
curl -s localhost:5002/api/health    # ישירות לשרת
curl -s localhost:8080/api/health    # דרך nginx
docker compose logs -f server        # make logs S=server
docker compose down                  # עוצר, שומר volumes
docker compose down -v               # מוחק DB + uploads (make clean)
# DB בדוקר, קוד native (לולאת עריכה מהירה)
cp .env.example .env                  # חובה! ברירות המחדל בקוד (root/lolsuit-dev) לא עובדות מול ה־DB של compose
docker compose up -d db               # MySQL על 127.0.0.1:3307
cd server && source .venv/bin/activate
python -m app.seed                    # פעם ראשונה
python run.py                         # API על 5002
python run_worker.py                  # טרמינל נוסף, אופציונלי
cd client && npm install && npm run dev   # http://localhost:5174, proxy /api → 5002
טריק להדגמה PHASE_MINUTES=2 ב־.env → כל המשפט (7 "ימים") לוקח 14 דקות. compose מעביר אותו גם ל־server וגם ל־worker.

Production (prod/): EC2 אחד (nginx + API + worker) מול Amazon RDS; images נמשכים מ־Docker Hub (release.sh בונה linux/amd64 עם buildx; deploy.sh pull → recreate → בודק /api/health → rollback אוטומטי). ${VAR:?} לסודות במקום ברירות מחדל.
