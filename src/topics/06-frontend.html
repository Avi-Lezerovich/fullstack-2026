בקצרה
  • App.tsx = טבלת הנתיבים. ProtectedRoute עוטף דפים שרק מחוברים רואים.

6.1 Bootstrapping

client/src/main.tsx עוטף מבחוץ פנימה: Emotion CacheProvider עם RTL stylis cache → ThemeProvider + CssBaseline → BrowserRouter → AuthProvider → NotificationProvider → App.

למה RTL פעמיים? direction: "rtl" ב־theme.ts הופך את הלוגיקה של MUI, אבל ה־CSS שנוצר עדיין צריך היפוך של properties פיזיים (margin-left ↔ right) — זה תפקיד stylis-plugin-rtl.

6.3 איך מדברים עם ה־API — client/src/api.ts
const BASE = "/api";
async function request<T>(path: string, init: RequestInit = {}): Promise<T> {
  response = await fetch(`${BASE}${path}`, { credentials: "include", ...init, headers: {...} });
  // network failure → ApiError(status 0, code "network")
  // !response.ok   → throw new ApiError(payload.error, response.status, payload.code)
}
export const createCase = (input: NewCaseInput) =>
  request<{ case: Case }>("/cases", json("POST", input)).then((r) => r.case);
  • אף קומפוננטה לא קוראת fetch ישירות — חריגים: hooks/useNotificationStream.ts (פותח EventSource בעצמו, ו־fetch ב־polling) ו־uploadImage (multipart, בלי ה־Content-Type של JSON).
  • credentials: "include" — אחרת הדפדפן לא מצרף את העוגייה.
  • ApiError נושא status + code מהשרת + הודעה בעברית — ה־catch כבר יכול להציג משהו.
  • types.ts משקף את shape_case/shape_comment בצד השרת — שינוי בצורה צריך לקרות בשני המקומות.
6.4 State management — contexts ו־hooks (אין Redux)
  • AuthContext (context/AuthContext.tsx): העוגייה httpOnly, אז הדרך היחידה לדעת מי מחובר — לשאול את השרת: /auth/me פעם אחת ב־mount. חושף user, loading, signIn, register, signOut, setUser.
  • NotificationContext: אחד בלבד ב־root — כי ה־stream הוא חיבור רשת אמיתי, ועותק שני היה פותח EventSource שני וסופר כל שורה פעמיים. הפעמון, badge ההודעות ודף Messages קוראים ממנו.
  • useAsync(loader, deps, intervalMs?): fetch → spinner → שגיאה בעברית; יש stale guard.
  • usePagedList(fetchPage, deps): רשימה מצטברת (offset), "טען עוד"; שינוי deps מאפס.
  • useNotificationStream: SSE, ואם יש 2 כישלונות תוך 30 שניות → polling כל 10s (POLL_INTERVAL_MS) לכל שאר ה־session. שני ה־transports מקדמים את אותו cursor.
