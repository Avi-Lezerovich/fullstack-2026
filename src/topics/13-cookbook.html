"Small change" cookbook — 25 שינויים שבוחן עלול לבקש

שיטת עבודה מול בוחן (60 שניות לפני שנוגעים בקוד)
  1. אמור בקול איזו שכבה מושפעת: UI (client/) / route (api/) / service (services/) / schema (init.sql) / config.
  2. grep לפני עריכה — הרבה ערכים משוכפלים בין לקוח לשרת (תוויות, מינימום סיסמה, מקסימום סעיפים).
  3. שנה, ואז הוכח: curl / דפדפן / טסט. אחר כך הרץ את הטסטים הרלוונטיים.
grep -rn "איסוף עדויות" client/src          # כל המופעים של טקסט
grep -rn "MIN_PASSWORD" server/app client/src
cd server && python -m pytest -m unit -q       # מהיר
cd client && npm run lint && npm test
פותח מתכון אקראי, כמו בוחן שמבקש שינוי. נסו לפתור לפני שקוראים.
