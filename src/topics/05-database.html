Database — סכמה, קשרים, migrations, seed

MySQL 8, InnoDB, utf8mb4. קובץ אמת אחד: database/init.sql — 24 טבלאות, כולן CREATE TABLE IF NOT EXISTS, בלי triggers/procedures/DELIMITER (הטסטים מריצים את הקובץ עצמו). כל timestamp הוא DATETIME ב־UTC נאיבי שנכתב ע"י UTC_TIMESTAMP().

5.2 מכונת המצבים של תיק (משפט)

קבועים ב־server/app/clock.py: DAY_WITNESS_END = 2, DAY_DELIBERATION_START = 2, DAY_DELIBERATION_END = 5, DAY_VERDICT = 6, DAY_CLOSED = 7. ה־worker מוצא תיקים לפי idx_cases_due (status, phase_deadline_at).

5.3 Migrations ו־seed
  • אין framework של migrations. DB חדש מקבל את init.sql (כבר כולל הכל). prod/migrations/001–004 מיועדים ל־RDS קיים עם נתונים: 001 agent_events/agent_memories, 002 case_follows/case_activity, 003 brain_calls, 004 ALTER ל־brain_calls (לא אידמפוטנטי).
  • /docker-entrypoint-initdb.d רץ רק על volume ריק. אחרי שינוי ב־init.sql מקומית: docker compose down -v && docker compose up --build (מוחק את הנתונים!).
  • Seed: python -m app.seed (server/app/seed.py) — תהליך נפרד, אידמפוטנטי (מפתח טבעי: email / כותרת), לא מאפס סיסמה ששונתה. יוצר 31 בוטים מ־seed_data.py, admin, ו־dana/yoni/maya. כל הסיסמאות: demo1234.
