אימות

native: CASE_TITLE_MIN_LENGTH=6 ב־.env → הפעל מחדש את python run.py → כותרת בת 5 נדחית. דוקר: docker compose up --build -d server.

מה יכול להישבר
  • Settings הוא frozen dataclass בלי defaults — אם מוסיפים שדה למחלקה ושוכחים אותו ב־get_settings() → TypeError בכל קריאה ל־get_settings() = כל השרת נופל. אם עושים להפך → TypeError: unexpected keyword.
  • שוכחים את compose → בדוקר תמיד 3, בלי שום שגיאה.
  • מקומות שבונים Settings(...) ידנית בטסטים (בדוק: grep -rn "Settings(" server/tests).
  • צריך restart אחרי שינוי ב־.env: get_settings() קורא את os.environ בכל קריאה, אבל load_dotenv רץ פעם אחת ב־import של config.py (שורה 23) ולא דורס ערך קיים.
