1. הרצה יומיומית (הדרך המהירה)

קודם כל: להפעיל Docker Desktop ולחכות שיהיה ירוק. אחר כך 3 טרמינלים, כולם מתיקיית הפרויקט.

אחרי שינוי בקבצי פייתון חייבים להפעיל את השרת מחדש: Ctrl+C ואז python run.py (אין reload אוטומטי). בקליינט מספיק לשמור קובץ והדפדפן מתעדכן לבד.

לעצור הכול (הנתונים נשמרים)

סטטוס קונטיינרים

לוגים (להחליף server ב-worker / web / db)

7. שחרור גרסה חדשה

הזרימה: במחשב שלכם בונים ודוחפים אימג'ים ל-Docker Hub, ובשרת (EC2) מושכים ומפעילים. השרת אף פעם לא בונה.

פורמט גרסה: vMAJOR.MINOR.PATCH עם v בהתחלה, למשל v5.0.1. Major עולה כשצריך צעד נוסף חוץ ממשיכת אימג' (למשל migration).

את הסקריפטים מריצים ב-Git Bash (מותקן עם Git) או ב-WSL, לא ב-PowerShell. צריך Docker Desktop רץ ו-docker login לחשבון Docker Hub.

א. להתחבר ל-Docker Hub (פעם אחת)

docker login

ב. הכול שמור ב-git? (השחרור מסרב לעבוד עם שינויים לא שמורים)

git status

ג. הרצת ניסיון - מדפיס מה יקרה ולא בונה ולא דוחף כלום

./prod/release.sh v5.0.1 --dry-run

ד. שחרור אמיתי + יצירת tag בגיט

./prod/release.sh v5.0.1 --git-tag

זה מפרסם 4 תגיות: lolsuit-server:v5.0.1, lolsuit-server:latest, lolsuit-web:v5.0.1, lolsuit-web:latest.

אפשרותמשמעות
--server-onlyרק אימג' השרת
--web-onlyרק אימג' הקליינט (תיקון בפרונט)
--no-latestלא להזיז את latest
--git-tagליצור ולדחוף tag בגיט
--allow-dirtyלבנות גם עם שינויים לא שמורים
-n, --dry-runרק להדפיס, לא לבצע

ה. בשרת EC2 - להפעיל את הגרסה (מושך, מחליף, בודק health, ואם נכשל חוזר אוטומטית לגרסה הקודמת)

cd /opt/lolsuit/prod && ./deploy.sh v5.0.1

חזרה לגרסה הקודמת ידנית (בשרת)

cd /opt/lolsuit/prod && ./deploy.sh --rollback

בשרת: סטטוס ולוגים של ייצור

docker compose -f prod/docker-compose.yml ps
docker compose -f prod/docker-compose.yml logs -f server
אם הגרסה מוסיפה טבלה (migration), מריצים את ה-SQL מ-prod/migrations/ לפני deploy. בלי זה האתר עולה ורק ה-worker נופל, בלי שגיאה ברורה. קחו snapshot קודם. פרטים ב-CHANGELOG.md וב-prod/README.md.

מה שכתוב כאן על השחרור והפריסה נלקח מהתיעוד ומהקוד של release.sh ו-deploy.sh (כולל --rollback). לא הרצתי שחרור או פריסה אמיתיים. עזרה מלאה: ./deploy.sh --help ו-./prod/release.sh --help.
