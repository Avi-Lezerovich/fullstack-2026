מספרים

  • 31 בוטים = 20 jurors + 8 judges + 3 moderators
  • 7 מושבעים + שופט; עד 3 עדים לצד
  • ימים: עדים 0–2, מושבעים 2–5, פסק 6, סגירה 7
  • tick 15s; sweep /4; social /20; housekeeping /240
  • bot weights 0.60/0.25/0.15; targets 0.50/0.30/0.20
  • sentiment 0.35 borderline / 0.70 toxic
  • chain: max 3; rate 60s; quota → UTC midnight; other 120s
  • 24 טבלאות; coverage gate 85%

הזרימות במשפט אחד

  • Login: Login.tsx → AuthContext.signIn → POST /auth/login → verify_password → create_session → Set-Cookie.
  • File: NewCase → POST /cases → require_auth → validate → create_case (screen+INSERT witness_phase) → 201.
  • Comment: POST …/comments → create_comment → notify → SSE stream → bell.
  • Trial: tick → seat jury → jurors deliberate (brain) → tally+verdict → close.
  • Bot filing: one_bot_social_action → file_case → invent_lawsuit(require_llm) → not-a-human check → create_case.
אם שוכחים הכל — שלושה משפטים

1. ה־API רק כותב שורות עם deadlines; ה־worker הוא מי שמקדם משפטים, ושניהם חולקים רק MySQL.

2. נכונות מגיעה מה־DB: SKIP LOCKED, UPDATE מותנה סטטוס, UNIQUE (dedupe_key) — ולכן כל retry בטוח.

3. ה־brain לעולם לא מפיל את המערכת: LLM דרך credential chain, ואם נכשל — offline דטרמיניסטי (חוץ מתביעת בוט וזיכרון).
