native: בטרמינל של python run.py. דוקר: docker compose logs -f server (או make logs S=server) — צריך docker compose up --build -d server כי הקוד אפוי ב־image.

למה זה מופיע בכלל?

server/run.py מגדיר logging.basicConfig(level=logging.INFO) ברמת המודול — כדי שגם תחת gunicorn log.info לא ייזרק (ברירת המחדל של root logger היא WARNING).
