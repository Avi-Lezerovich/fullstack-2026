תרגול תחת שעון — בדיוק כמו במבחן

במבחן מקבלים משימה קטנה ועושים אותה בפרויקט האמיתי, בלי AI, עם האתר הזה. כאן מתרגלים בדיוק את זה: משימה אקראית, שעון, ופתרון מוסתר. כל תרגול נשמר בדפדפן, אז רואים התקדמות.

איך מתרגלים
  1. בוחרים רמה ולוחצים "משימה חדשה". השעון מתחיל.
  2. עובדים ב־VS Code על הפרויקט המקומי. מותר הכול באתר (Ctrl+K, הקוד, ה־grep), חוץ מלפתוח את המתכון עצמו.
  3. תקועים? רמז 1 מראה איפה, רמז 2 מראה את השינוי. כל רמז נספר.
  4. כשזה עובד: טסטים, git diff, ולוחצים "סיימתי".
  5. מחזירים את הקוד למצב נקי: git checkout . (וקבצים חדשים מוחקים).

איך מסבירים לבוחן (30 שניות)

  1. איפה: "השינוי בשכבת ה־service, ב־cases_service.py, כי הכלל צריך לחול גם על…"
  2. מה עוד: "הערך הזה מופיע גם בלקוח (NewCase.tsx), אז עדכנתי גם שם, אחרת הטופס והשרת לא מסכימים."
  3. הוכחה: "בדקתי עם curl, קיבלתי 400 עם ההודעה החדשה, והטסטים עוברים."
  4. מה צריך לדעת: "בדוקר צריך --build, ותיקים קיימים לא משתנים כי הערך כבר כתוב בשורה."
